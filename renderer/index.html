Card density

The Claude Code sessions already on this machine that the dashboard isn't tracking. Tick the ones you still work on and say where each one belongs — the newest few are ticked for you, and nothing is written until the last step.

The dashboard's buttons — ＋ New, Resume, Close, Sync — don't do the work themselves. Each one opens Claude Code on one of this app's session skills, and the skill is what writes your notes.md. They live in ~/.claude/skills/ alongside your own, and only the names this app ships are ever touched — anything else of yours is invisible to it.

                Categories
              

              
A category mirrors a real folder at <root>/<NAME>. Pick existing folder(s) under one of your spaces (multi-select to add several). The app never creates or renames folders — name is read-only here; only the colour is editable. To rename a category (and move its folder) use the /rename-category skill; removing a row just drops it from the dashboard, the folder stays.
